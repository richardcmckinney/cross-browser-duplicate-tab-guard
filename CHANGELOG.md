# Changelog

User-visible changes and compatibility notes are recorded here. Repository changes may precede Web Store publication; check the installed extension and companion versions separately.

## 2.4.2 — Unreleased

### Added

- Pause controls in the duplicate alert and fallback chooser, with the same 15-minute, one-hour and 24-hour durations as the toolbar popup.
- Contributor instructions, issue and pull request templates, security reporting, privacy documentation and a release checklist.
- A reproducible helper to synchronize the Python installer's embedded extension assets with the extension source.

### Fixed

- Removed the generic trailing explanatory text from copied tab details while retaining the tab-specific fields.
- Removed matching installer-created external-extension registrations during uninstall while preserving externally modified or store-managed records.
- Restored embedded icons for standalone installs and removed machine-specific development paths.
- Clarified local data handling, private-context sharing, required companion setup and Web Store versus unpacked transport behavior.
