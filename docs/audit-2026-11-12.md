## Validation and its boundaries

Agent-run test execution took place on VSH; existing GitHub checks also validate the PR. The final local run passed 65 automated tests plus eleven coordinator self-checks. The test matrix includes coordinator self-checks, Python coordinator/installation regressions, deterministic Web Store package validation, JavaScript transport tests, Chromium popup/clipboard tests, and duplicate-pause tests.

The pause tests click both real interfaces through the production worker message handler, using isolated browser/coordinator API doubles. They verify every duration, settings preservation, no tab removal, invalid/stale requests, failed storage writes, fallback navigation and expiry/restart scheduling. Clock advancement verifies expiry without waiting a day.

A separate integration smoke test loaded the actual unpacked extension in a disposable Chromium profile and connected it to the production Python coordinator over a temporary loopback WebSocket. Only the temporary endpoint/token and native-host identifier were substituted to isolate the test from installed services. Real overlay clicks for 15, 60 and 1440 minutes each persisted the expected deadline, scheduled the matching `chrome.alarms` timestamp, cleared pending incidents and retained both actual tabs at their original URL. The temporary profile and processes were removed afterward.

Clipboard validation uses Chromium's actual clipboard write/read APIs and exact full-string comparisons, including private-context metadata and a Unicode title. It verifies removal of the final advisory without changing the preceding fields.

Package tests verify sorted deterministic ZIP contents, source asset parity, required icons, manifest resources, strict store CSP, native-only transport, removal of the development key and absence of local-token placeholders. Standalone installation is separately exercised without an adjacent extension folder, with operating-system registration/process effects mocked.

These results do not establish macOS execution, a complete store-installed native-messaging smoke test, or a live Chrome Web Store update. Existing regular/private cross-profile sharing is explicitly documented; pause remains scoped to the extension profile. Simultaneous settings edits remain a non-transactional storage limitation.
